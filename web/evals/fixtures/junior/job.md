Tessel Payments — Junior Backend Developer

You will:
- Build and maintain REST APIs in Python
- Write SQL against PostgreSQL and help tune slow queries
- Review code in Git pull requests
- Be on call during business hours, with support from a senior engineer

Nice to have:
- Exposure to Kubernetes or Docker
- Experience with Kafka or other message queues
- A computer science degree or equivalent projects
